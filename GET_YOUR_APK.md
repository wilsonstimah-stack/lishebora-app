# Get Your LisheBora APK (Installable Android App)

## Step-by-Step: Get Your APK File

### Step 1: Create GitHub Account (Free)
Go to https://github.com and sign up

### Step 2: Create New Repository
1. Click "New Repository"
2. Name it: `lishebora-app`
3. Make it Public
4. Click "Create"

### Step 3: Upload These Files
Upload all files from this folder:
- `main.py`
- `buildozer.spec`
- `lishebora_icon.png`
- `.github/workflows/build-apk.yml`

### Step 4: Wait for Build (5-10 minutes)
1. Go to "Actions" tab in your repo
2. Watch the build progress
3. When complete, click the workflow run
4. Download "LisheBora-APK" artifact

### Step 5: Install on Phone
1. Transfer the `.apk` file to your phone
2. Tap to install (enable "Unknown Sources" if prompted)
3. Done! App is installed and ready to use
